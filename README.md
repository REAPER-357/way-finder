# 🧭 Way-Finder Bookmark Manager

> A lightning-fast, offline-first Progressive Web App (PWA) bookmark manager built for privacy, speed, and seamless organization. Made by **REAPER-357**.

![Way-Finder Preview](icon.png)

## ✨ Features

* **⚡ Offline-First Architecture:** Powered by a local service worker and browser storage so your bookmarks are always accessible.
* **📂 Custom Folders & Tags:** Organize links into dedicated folders and filter instantly with tag support.
* **🕵️ Incognito Mode:** Flag specific bookmarks to stay private and secure.
* **🌗 Dark & Light Themes:** Toggle seamlessly between themes with a clean interface styled using Tailwind CSS.
* **📦 Backup & Restore:** Easily export your library to a JSON file or import existing backups (with built-in duplicate URL prevention).
* **🔒 100% Private:** Zero telemetry, zero tracking, and local-only data storage.

---

## 🚀 Tech Stack

* **Frontend:** HTML5, Tailwind CSS (via CDN)
* **Icons:** FontAwesome 6.4.0
* **PWA:** Web App Manifest & Service Worker (`sw.js`)
* **Storage:** LocalStorage

## 🛠️ Getting Started Locally

1. Clone or download the repository to your machine:
   ```bash
   git clone [https://github.com/REAPER-357/way-finder.git](https://github.com/REAPER-357/way-finder.git)

    Ensure your asset files (index.html, manifest.json, sw.js, icon.png, and small-icon.png) are in the root directory.

    Open index.html directly in any modern browser, or serve it via a local static server (e.g., Python's HTTP server or Node.js).

📱 Installing as a PWA

Way-Finder can be installed directly onto your desktop or mobile device as a standalone application:

    Open the app in a PWA-supported browser (like LibreWolf, Chrome, or Edge).

    Click the install prompt in your browser address bar or menu.

    Enjoy your native, desktop-ready bookmark hub!
